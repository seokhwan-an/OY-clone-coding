# OY-clone-coding

## 1단계 요구사항
- [ ] 상품을 등록한다.
  - [x] 상품 이름의 길이는 50자 이하로 한다.
  - [x] 상품 브랜드 명칭은 10자 이하로 한다.
  - [x] 상품 가격은 500,000원 이하로 한다. (음수 금지)
  - [ ] 관리자 계정을 통해서만 상품을 등록할 수 있다.
- [ ] 상품을 수정한다.
  - [x] 상품 이름의 길이는 50자 이하로만 수정 가능하다.
  - [x] 상품 브랜드 명칭은 10자 이하로만 수정 가능하다.
  - [x] 상품 가격은 500,000원 이하로만 수정 가능하다.
  - [ ] 관리자 계정을 통해서만 상품 정보를 수정할 수 있다.
